Sobre a senha

Este documento não contém a senha do powerbi_readonly, nem o tamanho dela, nem quais tipos de caractere ela usa, nem qualquer pista que ajude a reconstruí-la. Ela existe apenas no Secret Manager (powerbi-readonly-password) e na sua cabeça.

O que já está pronto no banco

Usuário PostgreSQL somente-leitura, sem acesso a dado pessoal cru. Verificado conectando como ele: leitura funciona onde deve, escrita falha em tudo.

ObjetoSituação
powerbi_readonlysem superusuário, sem criar banco, sem criar papel, sem herdar nada
8 tabelasSELECT liberado
4 viewsSELECT liberado
venda, usuario, alerta, historico_atividadesacesso direto negado — só pelas views

As views existem para tirar o que não deve sair: CPF e telefone de cliente em venda; nome, e-mail, identificador de autenticação e token de push em usuario; e os campos de texto livre digitados por pessoas em alerta e historico_atividades.

Passo a passo

  1. Autorizar sua máquina uma única vez

    O proxy usa Application Default Credentials, que são separadas do login normal do gcloud.

    gcloud auth application-default login
  2. Baixar o Cloud SQL Auth Proxy

    Baixe o executável e renomeie para cloud-sql-proxy.exe:

    https://storage.googleapis.com/cloud-sql-connectors/cloud-sql-proxy/v2.25.4/cloud-sql-proxy.x64.exe

    Não é preciso autorizar IP nenhum, e não é preciso instalar certificado no Windows — o proxy resolve as duas coisas.

  3. Ligar o banco

    Ele fica desligado por padrão, para não gerar custo.

    gcloud sql instances patch flemingcore-db-v2 --project=flemingcore-53272 --activation-policy=ALWAYS

    Leva alguns minutos até aceitar conexão.

  4. Deixar o proxy rodando

    Numa janela de terminal própria, que fica aberta enquanto você usa o Power BI:

    cloud-sql-proxy.exe --port 5432 flemingcore-53272:southamerica-east1:flemingcore-db-v2
  5. Conectar no Power BI Desktop

    Obter Dados → PostgreSQL

    Servidorlocalhost:5432
    Banco de dadospostgres
    AutenticaçãoBase de Dados (usuário e senha)
    Usuáriopowerbi_readonly
    Senhaa que você definiu

    Vai aparecer um aviso de conexão não criptografada. Clique OK. O trecho sem criptografia é só Power BI → 127.0.0.1, que não sai da sua máquina; o proxy faz o TLS até o banco.

    O Navigator vai listar as 8 tabelas e as 4 views. As tabelas base sensíveis não aparecem como acessíveis.

  6. Desligar o banco ao terminar

    Feche o proxy e rode:

    gcloud sql instances patch flemingcore-db-v2 --project=flemingcore-53272 --activation-policy=NEVER
Evite a janela 06:00–06:10 (horário de Brasília)

É quando o orquestrador da projeção diária roda. Ele liga o banco, gera os alertas e desliga o banco no final, por garantia — inclusive se você estiver usando. Se o Power BI perder a conexão nesse horário, é isso, não é defeito.

Os três últimos não se resolvem com mais tempo de Power BI. Os dois do meio precisam de dado gerado; o último precisa de mudança de modelagem, porque não existe tabela de histórico guardando os valores ao longo do tempo.
